Merchandiser 业务流程与说明
本地桌面跟单工具。模型：仓位差额同步 + 挂单镜像。卡片可点击跳到对应页面。
主流程：首次使用到稳定运行
01 连接
添加跟单账户 API
自动校验连通、权限、持仓模式；有提币权限红色警告
02 信号源
添加 HL 地址 / 只读 API
地址 42 位校验；实时查看对方持仓与挂单
03 新建任务
五步向导
信号源 → 跟单账户 → 规则 → 风控 → 确认；必填项为空时下一步禁用
04 任务详情
启动并对账
按启动策略处理已有仓位；仓位对比、挂单镜像、执行日志
05 总览
日常监控
总权益、任务偏差刻度、告警；最小化到托盘后台运行
06 记录
复盘与导出
执行日志按 跳过 / 失败 筛选，导出 CSV
分支与异常路径
全局急停（顶栏常驻，任意页面）
点击后所有任务立即暂停、撤销全部镜像挂单，不平仓。总览出现急停横幅，可选「恢复」（先对账）或「全部平仓」（二次确认）。
信号丢失 / 断线重连
信号源断线超过阈值：任务挂起、不新开仓，顶栏健康点变黄。重连后自动全量对账，无偏差才恢复跟单；偏差超阈值时提示用户选择补齐或保持。
风控触发
单品种 / 总名义上限：超出部分跳过并记日志。滑点超限：本次不下单。日亏损 / 累计亏损上限：任务自动暂停并通知，需手动恢复。
下单失败与跳过
限频 / 网络错误自动重试 3 次后记失败；无对应合约、低于最小变化阈值、名单外品种记为跳过。下一次对账会再次尝试补齐差额。
业务规则
· 只支持 USDT / USDC 永续合约；跟单账户须为单向持仓模式。
· 目标仓位 = 信号仓位 × 系数（权益比例 / 固定倍数 / 固定名义）；下单量 = 目标 − 实际，小于最小变化阈值不下单。
· 减仓与平仓优先、使用只减仓；加仓受风控上限约束。
· 挂单镜像：信号源挂单 2 秒宽限后镜像；镜像单先于信号成交造成的偏差属预期，由下次对账收敛。
· 杠杆：跟随信号或固定值，均受上限约束。
· 密钥存系统钥匙串，前端拿不到明文；HL 只接受 API 钱包私钥。
· 交易所带单员信号源、收益报表、Telegram / Webhook 通知为第二期。
原型中的交互状态
· 顶栏「全局急停」：所有页面可点，总览显示急停横幅与恢复 / 全部平仓。
· 跟单任务列表：状态分段筛选（全部 / 运行 / 暂停 / 停止）。
· 任务详情：暂停 / 恢复切换；仓位对比 / 挂单镜像 / 执行日志 tab。
· 新建任务向导：仓位模式、杠杆、启动 / 停止策略可切换；系数为空显示错误并禁用下一步。
· 信号源：添加 HL 地址弹窗，地址不足 42 位提示错误。
· 连接：添加连接抽屉，平台切换（OKX 多 Passphrase，HL 换成 API 钱包字段与警告）。
· 记录：三个 tab，日志按 全部 / 跳过 / 失败 筛选。设置：二级导航、开关、分段选择。
动效规范
· 缓动统一 cubic-bezier(0.2, 0.8, 0.2, 1)（快出慢停）；颜色类用 ease。交易工具保持克制：不弹跳、不超过 260ms。
· 状态色（tab 文字、分段选中、按钮 hover、选中描边、错误描边）：color / background / box-shadow 150ms。
· Tab 下划线：从中心 scaleX 0 → 1，220ms；切换后新面板淡入并上移 4px，200–220ms。
· 筛选 / 二级导航切换：列表行与面板只做淡入 220ms（不位移，避免表格内跳动）。
· 弹窗：遮罩淡入 200ms，弹窗体淡入 + 上移 12px + 0.98→1 缩放 220ms；关闭反向播放后再卸载（240ms）。
· 右侧抽屉：遮罩与抽屉淡入淡出 220ms；正式实现可改为从右侧滑入 translateX(100%)→0，260ms。
· 开关：圆点平移 16px + 底色变化 200ms；单选圆点从 0.3 缩放出现 200ms；急停横幅淡入淡出 220ms。
· 系统开启「减少动态效果」时，全部过渡时长降为 0。
